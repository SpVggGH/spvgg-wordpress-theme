# SpVgg Lagerlechfeld-Graben – WordPress-Theme (Vorschau)

Vorschau des neuen Website-Themes der SpVgg Lagerlechfeld-Graben e.V., direkt im Browser – ohne Installation:

**[▶ Vorschau im WordPress Playground öffnen](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/SpVggGH/spvgg-wordpress-theme/main/blueprint.json)**

Jeder Aufruf startet eine eigene, frische Test-Website im Browser (WordPress Playground). Änderungen dort werden nirgends gespeichert und betreffen niemanden sonst. Backend: `/wp-admin`, Benutzer `admin`, Passwort `password` (gilt nur in dieser Wegwerf-Instanz).

## Inhalt

| Datei | Zweck |
|---|---|
| `spvgg-theme.zip` | Das Theme – lässt sich auch in jedem WordPress unter *Design → Themes → Theme hochladen* installieren |
| `spvgg-demo.zip` | Demo-Inhalte für die Vorschau (Seiten, Beiträge mit Platzhaltertext, Demo-Bilder) |
| `blueprint.json` | Anleitung für den Playground: Theme installieren, Demo-Inhalte anlegen |

Hinweise zur Vorschau:

- Die **nächsten Spiele** kommen live aus den offiziellen iCal-Exporten des BFV.
- Die **Ergebnisse** sind erfundene Demo-Daten (z. B. „Demo SV Musterstadt“).
- Die **Wappen der Gegner** stammen aus einem Schnappschuss; neue Gegner erscheinen in der Vorschau mit Kürzel.
